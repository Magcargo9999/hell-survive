## 1. 사용자 선호 (꼭)
- 파일 이름은 매 빌드 `hell survive v.N.NN.html`, 버전은 매번 올린다. 끝자리=작은 수정 · 가운데 자리=캐릭터·보스 추가 같은 큰 변화.
- **도트·맵은 절대 수정·재색칠 금지.** 자르기·배경 제거·마스크·배율 조정만 허용. **확대는 정수배 + 보간 없음(nearest)** 이어야 도트가 안 번진다. (v6.20에서 맵을 3.5배로 키웠다가 "도트 깨진다"고 지적받아 v6.21에서 고침 — 맵 공간을 넓힐 땐 **그림 일부를 복사해 이어 붙이는 방식**을 쓴다.)
- 기능은 **단순하게**. 서로 복사한 듯한 중복 스킬/카드 금지. 새 캐릭터는 자기 복제형 스킬을 줄인다.
- 지시받은 것만 적용한다. 임의로 범위를 넓히지 말고, 임의로 정한 부분은 마지막 보고에 꼭 적는다.
- 오래 걸리는 시뮬레이션은 사용자가 원할 때만.
- 답변은 짧게. 만든 것·주의점·임의 결정만 요약.

## 2. 꼭 지킬 규칙
1. **파일 이름:** 매 빌드 `hell survive v.N.NN.html`, 버전은 매번 올린다. 마지막 배포 = **v6.21** → 다음은 v6.22. (v6.01부터 번호 체계가 6대로 바뀜)
   - 끝자리: 작은 수정 · 가운데 자리: 캐릭터·보스 추가 같은 큰 변화.
2. **도트는 절대 수정·재색칠 금지.** 자르기·배경 제거·마스크·배율 조정만 허용.
3. 기능은 **단순하게**. 서로 복사한 듯한 중복 스킬/카드 금지.
4. **규격표 ①~⑩**(`docs/hell survive 규격표 v4.15.pdf`)을 따른다. 규칙을 깨야 하면 먼저 허락받는다.
   - 소폭 ±6~10% · 중폭 ±11~20% · 대폭 ±21~35% · 재설계급 35%+ (스탯별 보정 배율은 규격표 ②).
   - 소개 문구는 역할 하나 + 약점 하나 (규칙 ⑤).
5. **1진화에는 스킬을 넣지 않는다** (사용자가 직접 요청한 경우만 예외: 연보라 총령 차지샷, 문어 마법사 코끼리 돌진).
6. **매 버전 GitHub 커밋 + 푸시** (아래 배포 절차). 커밋 메시지에 변경점 한 줄.
7. **티어 결과를 줄 때는 항상 보스별 상성 + 티어표 사이트에 들어갈 값(s2/s1 JSON) 전부 포함**해서 PDF로 준다 (`docs/`의 기존 "티어표 추가" PDF 형식 참고).
8. 오래 걸리는 시뮬레이션은 사용자가 원할 때만. "오래 걸리면 하지 마" 라고 한 적 있음.
9. **화면·보스방 전체를 덮어 어디에도 안전한 곳이 없는 패턴(무조건 못 피하는 패턴)은 넣지 않는다.** 이속 강화를 안 찍어서 못 피하는 건 괜찮지만, 이속을 끝까지 찍어도 피할 안전 구역·통로·시간이 없는 패턴은 안 된다. 새 패턴·난이도 배율을 넣을 때 최고 단계(5단계)에서도 안전 구역이 남는지 확인한다. (예: 흡혈 고리의 안전 통로 `inTeleGap`)

## 4. 챌린지 모드 현재 상태 (v6.21) — 알아둘 점
- 해금: 난이도 5단계 마왕 처치(`SAVE.ch.open`). 시작 화면 [∞ 챌린지 모드].
- **맵:** 원본 그림(1672×941)을 정수 2배·nearest로 그리고, 가운데 띠(가로 596~908, 세로 318~596)를 3번씩 복사해 이어 붙인다 (`CHM.cols/rows`, `drawChMap`). 맵 약 5216×3550. 가장자리 용암·벽은 막혀 있어 끝없는 맵은 아니다. 복사 이음새에서 기둥이 살짝 잘려 보이는 곳이 있다(사용자가 거슬린다고 하면 이음새 위치·복사 횟수 조정).
- 5레벨마다 강적 1마리, 15레벨 단위로 반복(사이클마다 강해짐), 룬 조각(챌린지 전용), 보물 3종(모든 모드에서 효과), 황금 도망자 · 엘리트 접두사(20분~) · 쉼터 · 심연 추격자(25분~).
- 신규: 절단안의 짐승(미니보스), 심연의 촉수마왕(마왕). 둘 다 챌린지 전용(시트에는 "원숭이 마왕과 같은 확률로 나오는 희귀 보스"라 적혀 있었음 → 일반 모드에도 넣을지 사용자에게 확인 필요).
- 챌린지 맵에는 밟을 수 있는 용암이 없어서 용암 달팽이 진화 조건을 챌린지에서는 없앴다.
- **밸런스 시뮬은 안 돌렸다.** 잡몹 체력·젠 증가, 보스 체력, 룬·보물 속도는 전부 추정값. 사용자가 플레이 후 체감 보고하면 조정.

## 6. 코드 수정 요령
- 템플릿 수정은 **파이썬 문자열 치환(정확히 1회 일치 assert)** 이 안전했다. 주석을 줄 중간에 넣으면 뒤 코드가 주석 처리되니 주의 → `check.py`가 잡는다.
- 테스트용 전역 `window.__G`에 내부 함수를 노출한다. 새 기능을 테스트하려면 `__G`에 추가.
- 세이브 키 `hellSurvivorSave1`은 **절대 바꾸지 말 것** (사용자 진행이 날아감).
- 새 스킬 함수는 파일 끝 `skWrap` 목록에 추가해야 딜 미터기에 잡힌다.
- 이미지 시트를 새로 넣을 땐 `src/build.py` 토큰 표 + `SRC` + (큰 시트면) `hq` 배율 예외를 같이 확인. 4096px 초과 캔버스는 느려진다.

## 게임 구조 요약 (src/game_template.html, 약 6,500줄)
- **캐릭터** `CHARS`: wolf, snail, archer, chimera, lizard, twins(사슬 악마, 벨리아·셀리아 처치 해금), ghost(연보라 구슬 유령), octo(문어 마법사, 히든: 난이도 2+ 유니크 몹 처치 해금). 각 `role`/`weak` 필드 = 카드 앞면 문구.
- **진화:** Lv.10 루트 선택 → Lv.20 최종 (용암 달팽이는 Lv.25 3단계). `applyEvo(to)` 에 캐릭터별 스탯. 폼 데이터: `ROUTE_FORMS`, `SNAIL_FORMS/VENOM_FORMS/LAVA_FORMS/BOMB_FORMS`, `ARCHER_*`, `CHIM_FORMS`, `LIZ_FORMS`, `TWIN_FORMS`, `GHOST_FORMS`, `OCTO_FORMS`. 프레임별 사각형 `anim.X.fr=[[x,y,w,h,ax,ay]…]`.
  - 달팽이 루트: venom(맹독) / lava(용암) / **bomb(폭탄, v5.13 추가)**: 기본 공격 폭탄 1→4번째 점점 커짐, 폭발 자리 불웅덩이, 최종 스킬 megabomb.
  - 리자드 루트: sword(→ rage/water) / guard(수호의 길 → 수호의 리저드, 스킬 shell 반격의 갑주).
  - 늑대 혈랑 최종: blood / holy / fallen(타락한 혈랑, 숨은 보스 처치 시 열림, 스킬 bsigil 혈왕의 진).
- **스킬:** `SKILLS`, `SKILL_CD`(쿨타임 초), `uniqueSkill(s)()`, `castSkill()`.
- **카드:** `UPGRADES`(공용, `alt: {캐릭터/루트: [이름, 문구]}`로 캐릭터별 이름), `UNIQUE`(캐릭터 전용), `SYNERGIES`(★조합, 재료 2장 Lv.3, `only:` 전용). `cardView`, `openChoice`(카드 앞면=효과, 누르면 뒷면=조합 / 진화 갈림길이면 이후 최종 진화), `openUpgrade`(기본 3장, 상점 '넓어진 선택지'면 4장).
- **강화 상점** `PERKS` (캐릭터 상점과 분리): hp/spd/dmg/exp/magnet 각 10, banish 5, regen 3(초당 +0.1), shard 5(+5%), critd 5(+10%p), choice 1(5000), revive 1.
- **재생:** 기본 재생 없음(상점 구매). 캐릭터별 P.regen만 (1.2초 이상 정지 시 25%).
- **보스:** 원숭이 / 마안군주(eye) / 스켈레톤(skel, 난이도1+) — 마왕성 보스방 `ARENA` (배율 `AS=1.25`), 숨은 보스 타락한 혈랑왕(fw) — 제단 `BMAP`(s 1.65). 흡혈 고리 패턴에 안전 통로(`inTeleGap`). 마안군주 기둥은 장식만(충돌 없음).
- **유니크 몹** `UNIQ`: 한 판에 종류별 1회, 난이도 3+ 은 동시에 2마리까지.
- **난이도:** 몹 체력 단계당 +10%, 보스·미니·유니크 +30%.
- **HUD:** 체력바 아래 획득 카드 칩, 캐릭터 머리 위 체력바, 설정의 딜 미터기(`DSRC` 태그 → `DMETER`), 성유물·슬롯 화면밖 화살표.
- **세이브:** localStorage `hellSurvivorSave1` (기기·브라우저별). 키를 바꾸면 사용자 진행이 날아가니 절대 바꾸지 말 것.
- **∞ 챌린지 모드 (v6.20, 템플릿 'v6.20 ∞ 챌린지 모드' 블록):** 난이도 5단계 마왕 처치 시 해금(`SAVE.ch.open`, 예전 5단계 클리어 스펙 `fw.snap.tier>=5`도 인정). 시작 화면 [∞ 챌린지 모드] 버튼 → `chMode` → `startChallenge`. 전역 `chal`(판 상태), `CHM`(맵 그림 정수 2배 + 가운데 띠 복사 · 다각형 `inCh` · 밖은 `chPull`).
  - `P.tier=2`(마왕 패턴 기믹 약화). 잡몹 체력 `chTime()`(10분까지 원래 속도, 이후 절반) · 생성량/상한 천천히 · 공격력 `chDmgT`.
  - 5레벨마다 강적 1마리(`chEvent`): Lv%15=5 `CH_EV_A`(미니·히든·유니크) / =10 `CH_EV_B`(미니·히든) / =0 `CH_BOSS`(원숭이·마안·스켈레톤·혈랑왕·촉수마왕). 사이클 `chal.cyc`마다 강해짐. 마왕은 보스방(촉수마왕만 필드) → 처치 후 원래 자리로 돌아와 쉼터(`chShelter` 10초 + 안식/어둠의 계약).
  - 룬 조각 `chFrag`(15개=룬 1개, 8종 스탯 각 5단계, 챌린지에서만 적용, `SAVE.ch.rune/frag`). 보물 `TREASURES`(사망 시 버틴 시간 10/15/20분, 모든 모드에서 효과, `SAVE.ch.tr`): 쥐 이빨 목걸이 · 도깨비 주머니(`dropChest`) · 깨진 거울.
  - 황금 도망자(`chGoldSpawn`) · 엘리트 접두사 20분~(`chPrefix` 빠름/분열/보호막 `e.shd`) · 심연 추격자 25분~(`chal.chaser`, 이속 100, 불사).
  - 신규 미니보스 절단안의 짐승(`mini.bk='cut'`, 원본 대기·이동은 왼쪽/공격 줄은 오른쪽을 봄) · 신규 마왕 심연의 촉수마왕(`boss.bk='ab'`, 하수인 kind `abm`, 추종하는 눈 = ebul k `abeye`). 둘 다 챌린지 전용.
- **쿠폰:** 설정에서 `ai소프트웨어학과` 입력 → 문어 마법사 최종 스킨 (접속마다 재입력).

## 티어 측정 방법
- `tools/sim600.py` 의 `VAR` 표에 변형 키(예 `'snail:bomb':('snail','bomb','')`)가 있어야 한다.
- `tools/tier_run.sh "<키>" <이름>` (약 30분) → `python3 tools/tier_an.py build/tier/<이름>_boss.txt build/tier/<이름>_field.txt "최종 이름" "1진화 이름"`
- 점수 = 보스 평균 깎은 체력 75% + Lv.24 필드 처치 25%, 기존 1등 = 100. S≥92 · A≥80 · B≥64 · C≥56 · D.
- 보고서: 보스별(원숭이/마안/스켈레톤/혈랑왕) 깎은 체력·승리·평균 대비 상성 + s2/s1 JSON → PDF.
